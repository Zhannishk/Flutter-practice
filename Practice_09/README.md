# Flutter Practice 9 — Book Shop

This repository contains the final Provider implementation and an initial `lifted` commit.

## Run
1. Install Flutter SDK.
2. From this directory run `flutter create --platforms=android,ios,web .` to generate missing platform folders (choose only platforms configured on your machine).
3. Run `flutter pub get`.
4. Run `flutter run`.
5. Run `dart format .` and `flutter analyze`.

## Screens
- Books: search, add each book once, cart badge.
- Cart: increment quantity, remove books, clear with confirmation, total price.
